# @devsync/config

Shared development configuration for the DevSync workspaces.

## What exists today

- `tsconfig.base.json` — the strict TypeScript base that the shared packages extend.

## Future responsibility

This package will own the development configuration that more than one workspace
needs to agree on: shared ESLint configuration, Prettier configuration, and the
shared test-runner configuration.

`apps/web` and `apps/api` currently keep the ESLint configuration generated by
their own framework toolchains. Consolidating those behind this package is
deliberately deferred to a later Phase A milestone.
